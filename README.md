# One Bangkok — Incident Report Executive Dashboard

Interactive Executive Dashboard for One Bangkok incident reporting, trend analysis, and preventive mitigation monitoring (2024–2026).

## Key Features
- **Bilingual Interface**: Seamless toggle between **Thai (TH)** and **British English (GB)** with pure language segregation.
- **Dual Visual Modes**: **Day Mode (☀️)** and **Night Mode (🌙)** with high-contrast accessibility.
- **Locked Top Navigation**: Sticky header and scorecard bar remain accessible during table browsing.
- **Yearly Trend Analytics (2024–2026)**: Dynamic case count and interactive year filtering.
- **Dynamic Category & Component Drilldown**: Instant recalculation across 12 One Bangkok asset components and standard incident categories without unclassified "Other" entries.
- **Standardized Severity & Injury Care**: 4-level Injury Severity Rating (Major, Moderate, Minor, Insignificant) and 4-level Injury Response (Emergency, Medical, First Aid, Nil).
- **Multi-Format Export**:
  - **PowerPoint (.pptx)**: Built to 16:9 widescreen layout styled with **Frasers Property Corporate Identity** (Navy & Red Ribbon).
  - **Word (.docx / .doc)**: Formatted executive summary report with full tables.
  - **PDF Document**: Executive print / PDF export layout.
